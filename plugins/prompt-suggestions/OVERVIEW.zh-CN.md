提示词建议会在 Agent 每轮结束时，预测你接下来最可能发送的消息，让你一个按键就能发出去。

在网页版和桌面版里，建议会以灰色占位文字显示在 Agent 的输入框里。在空输入框里按 Tab 即可填入，之后可以修改，或直接按 Enter 发送。输入其他内容会让建议消失，Agent 开始下一轮时建议也会消失。在没有 Tab 键的地方，也就是 iOS 和 Android 应用以及手机尺寸的网页（手机浏览器或安装到桌面的网页应用），建议会改为显示在 Agent 最后一条回复下方的小卡片里，带有“发送”和“复制”按钮。

建议从对话的第二轮开始出现，并且只跟在正常完成的一轮之后。子 Agent 不会收到建议。

## 准备工作

需要 Paseo 0.11.2 或更高版本，并且在 daemon 所在的机器上安装并登录 Claude Code CLI（`claude`）。默认情况下，无论你在和哪个 Agent 对话，每次预测都通过这个 CLI 在 Claude Haiku 上运行。

在 Paseo 0.13 及以上版本中，插件的文字会跟随应用的语言，显示英文或简体中文；更早的版本显示英文。

## 设置

在“设置 → 插件”里，打开“提示词建议”的 ⋯ 菜单并选择“设置”。这些设置由同一主机的所有客户端共享：

- **为哪些 Agent 生成建议**：所有 Agent（默认），或仅 Claude Agent。选择仅 Claude Agent，可以避免把你和 Codex、OpenCode 等其他 Agent 的对话发给 Anthropic。
- **模型**：最新 Haiku（默认）、最新 Sonnet 或最新 Opus，它们会跟随各系列的最新模型；也可以从 Paseo 为 Claude Agent 提供的列表里选一个具体的 Claude 模型。更大的模型预测更慢，也会消耗更多 Claude 用量。

选择后立即保存，从下一次预测开始生效，不需要重新加载插件。

## 发送了什么、发到哪里

每轮正常结束后，插件会取对话中最近的一部分（用户和 Agent 的消息，以及每次工具调用的一行名称和状态，最多约 6,000 个字符），交给 daemon 所在机器上的 `claude -p`，由它发送给 Anthropic。除非你在设置里选择仅 Claude Agent，否则这适用于所有 Agent：和 Codex、OpenCode 或其他非 Claude Agent 的对话，这部分内容同样会发给 Anthropic 用于预测。这次运行没有工具、没有 MCP 服务器、没有 hooks，也不保存会话，所以它无法操作你的项目，也不会出现在你的 Claude Code 历史里。它不会加载你的 CLAUDE.md、规则或记忆文件，所以你个人的 `~/.claude/CLAUDE.md` 不会被一起发送。你的 Claude Code 设置仍然生效，因此你在那里配置的网关、代理、Bedrock 或 Vertex，以及 `apiKeyHelper` 都会照常使用。每次预测和其他请求一样计入你的 Claude 用量。建议会在一轮结束后两到五秒出现。

所有 Agent 加起来最多同时运行两个预测，其余的排队等候。15 秒内无法开始的预测会被跳过；如果还在排队时 Agent 已经开始下一轮，这次预测就不会再运行。

## 限制

网页版和桌面版的占位文字依赖 Paseo 应用当前渲染输入框的方式，而不是插件 API。如果 Paseo 更新改变了这一点，插件会退回到卡片显示，而不是占位文字。建议保存在 daemon 的内存里，daemon 重启后就会消失。目前插件只在 Claude Code Agent 上测试过。
