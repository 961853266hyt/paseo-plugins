# Changelog

## 0.1.0

First release.

- An **Annotate** button on the app's image viewer opens any chat image, from the message box, a
  sent message or an agent's reply, in an editor with pen, arrow, rectangle, text, blur and crop
  tools, six colors, three sizes, undo and redo.
- **Add to message** puts the marked-up PNG into that chat's message box and, for an image from
  the message box, can replace the original. Copy and Download are there too.
- Web and desktop app, Paseo 0.12 or later, in English or Simplified Chinese on Paseo 0.13.
