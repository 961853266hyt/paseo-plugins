Image markup 让你在把截图发给 Agent 之前先做标注，全程不用离开 Paseo：在图上画、指出位置、遮住敏感信息、裁剪，改好的图会直接回到输入框里。

粘贴或添加一张图片，点输入框里的缩略图打开它，再点查看器左上角的**标注**。已发送消息里的图片和 Agent 回复里的图片上也有这个按钮。

编辑器提供：

- **画笔**（P）、**箭头**（A）、**矩形**（R）和**文字**（T），六种颜色、三种粗细。文字写在点击的位置，回车完成，Shift+回车换行。
- **打码**（B）把选中区域变成粗马赛克，密码、令牌、姓名都无法还原。
- **裁剪**（C）只保留拖出的区域；用裁剪工具单击一下即可取消裁剪。
- 撤销和重做（Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z）、复制到剪贴板、下载为 PNG。

**添加到消息**（Ctrl/Cmd+Enter）会把标注后的 PNG（保持原图分辨率）放进这张图所在聊天的输入框。如果图片是从输入框打开的，**替换原图**（默认勾选）会同时移除未标注的那张。来自已发送消息或回复的图片会作为新附件加入。按 Esc 关闭编辑器，不做任何改动。

## 使用条件

需要 Paseo 0.12 或更高版本的网页版或桌面版。在 Paseo 0.13 及以上版本中，插件文字会跟随应用语言显示英文或简体中文；更早的版本显示英文。

## 读取和发送的内容

所有操作都在你设备上的应用里完成。插件读取查看器里显示的图片，再像你手动粘贴一样把结果交给输入框，由应用像保存普通粘贴截图那样保存和发送。插件没有服务端部分，自己不向任何地方发送数据。

## 限制

- 仅支持网页版和桌面版，iOS 和 Android 应用不会运行它。
- Paseo 没有供插件读写输入框附件的 API，所以插件依赖应用页面里的图片查看器、输入框和图片缩略图。如果 Paseo 更新改动了这些部分，插件可能会失效，直到插件随之更新。
- 和普通粘贴一样，只有在主机已连接且语音输入关闭时，输入框才会接收图片。
- 托管在其他网站上的图片只有在该网站允许（CORS）时才能打开；附件和粘贴的截图总是可以。
- Paseo 只在发送消息的那个窗口里显示已发送消息中的图片，所以刷新后只能标注 Agent 回复里的图片和输入框里的图片。
